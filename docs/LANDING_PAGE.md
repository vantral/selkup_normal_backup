# Справочная страница корпуса

Содержимое главной страницы хранится в `conf/about.md`. Этот файл подключается
в контейнер отдельно от кода, поэтому после изменения Markdown достаточно
обновить страницу в браузере: пересборка образа не требуется.

В начале файла находится блок параметров:

```text
Title: Название корпуса
Subtitle: Подзаголовок
Accent: #2f6f68
Search-button: Открыть поиск
Show-stats: true
Show-grammar: true
```

После пустой строки начинается обычный Markdown. Поддерживаются заголовки,
списки, ссылки, цитаты, таблицы и встроенный HTML. Из заголовков автоматически
строится навигация по странице.

Блок статистики строится по индексам Elasticsearch и показывает количество
текстов, предложений и слов. Каталоги грамматических тегов и глосс строятся из
`conf/categories.json`, `gramm_selection` и `gloss_selection` в
`conf/corpus.json` и сохраняют порядок элементов поискового селектора.
Отображаемые названия языков задаются там же в `landing_language_names`.
Чтобы скрыть автоматические блоки разметки, установите
соответствующий параметр в `false`.

Маршруты:

- `/` и `/about` — справочная страница;
- `/search` — поисковый интерфейс TsaKorpus.

После изменения Python, HTML, CSS или `requirements.txt` образ нужно
пересобрать. Для изменения только `conf/about.md` это не требуется.
